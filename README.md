# 🗂️ BOB - Workspace Organizado por Projetos

Este workspace está organizado com projetos completamente separados em pastas dedicadas.

## 📁 Estrutura de Pastas

```
BOB/
├── projects/                    # Pasta principal de projetos
│   ├── copa-2026-dashboard/    # Dashboard Copa do Mundo 2026
│   │   ├── index.html
│   │   ├── README.md
│   │   ├── css/
│   │   ├── js/
│   │   ├── assets/
│   │   └── ...
│   │
│   └── [outros-projetos]/      # Futuros projetos aqui
│
├── .gitignore                   # Configuração Git global
└── README.md                    # Este arquivo

```

## 📝 Como Adicionar Novos Projetos

1. Crie uma nova pasta dentro de `projects/`
2. Nomeie a pasta com o nome do projeto (use kebab-case)
3. Adicione todos os arquivos do projeto dentro dessa pasta
4. Crie um README.md específico para o projeto
5. Atualize este README.md principal com informações do novo projeto

## 🎨 Convenções de Nomenclatura

- **Pastas de projetos:** `kebab-case` (ex: `meu-novo-projeto`)
- **Arquivos:** Seguir convenções do projeto específico
- **Documentação:** Sempre incluir `README.md` em cada projeto

## 🔧 Configuração

- **Git:** Configurado com `.gitignore` global para todos os projetos
- **IDE:** Configurações do VSCode aplicam-se a todo o workspace

## 📚 Recursos

- Cada projeto mantém sua própria documentação
- Projetos são completamente independentes
- Fácil navegação pelo VS Code Explorer
